# เกมพอนด์ 🌱

เกมพอนด์ (GamePond) คือแพลตฟอร์มการเรียนรู้ด้านการเกษตรในรูปแบบเกม (Game-Based Learning) ที่ออกแบบมาเพื่อให้ผู้ใช้งานได้รับทั้งความรู้และความสนุกไปพร้อมกัน

## คุณสมบัติ

* ระบบฟาร์มเสมือนจริง
* ปลูกและเก็บเกี่ยวพืช
* ระบบร้านค้าและไอเทม
* ระบบเงินภายในเกม
* เรียนรู้เกี่ยวกับพืชและโรคพืช
* รองรับการใช้งานบนคอมพิวเตอร์และอุปกรณ์พกพา

## เทคโนโลยีที่ใช้

* HTML5
* CSS3
* JavaScript

## วิธีใช้งาน

1. เปิดเว็บไซต์
2. เริ่มต้นสร้างฟาร์ม
3. ปลูกพืชและดูแลแปลงเพาะปลูก
4. เก็บเกี่ยวผลผลิต
5. สะสมเงินและพัฒนาฟาร์ม

## โครงสร้างโปรเจกต์

## การติดตั้ง

Clone โปรเจกต์

```bash
git clone https://gitlab.com/USERNAME/gamepond.git
```

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ หรือ Deploy ผ่าน GitLab Pages
